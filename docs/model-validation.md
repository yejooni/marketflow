# 돌파 확률 모델 검증 (Model validation)

`python -m pipeline.backtest` 로 재현할 수 있습니다. 모델을 수정하면 이 문서를 갱신하세요.

## 모델

오늘 장중 고가가 기간 신고가 `H` 를 넘으려면 종가 `C` 기준 `r = H/C - 1` 만큼의
상승이 필요합니다. 분포를 가정하는 대신, **이 종목이 실제로 그만한 움직임을
얼마나 자주 냈는지**를 셉니다.

```
h_t  = High_t / Close_{t-1} - 1        일간 상방 확장폭
z_t  = h_t / sigma_{t-1}               직전까지의 변동성으로 표준화
z_req = r / sigma_now

P = (z_t >= z_req 인 과거 세션의 비율)
```

변동성으로 표준화하는 이유는, 변동성 국면이 바뀐 종목에서 단순 빈도가
과거 기준으로 오늘을 잘못 평가하기 때문입니다.

## 검증 방법

무작위 250종목 × 종목당 40거래일을 샘플링해 **그 시점까지의 데이터만으로**
1개월 신고가 돌파 확률을 계산하고, 다음 거래일에 실제로 돌파했는지 확인했습니다
(9,336건). 학습이 없는 순수 빈도 모델이라 과적합 여지는 없지만, 예측 시점 이후
정보가 새지 않도록 `sigma`는 항상 직전 세션까지의 값만 사용합니다.

## 결과

전체 평균 예측 **9.47%** vs 실제 관측 **9.45%**

| 예측 구간 | 표본 | 평균 예측 | 실제 돌파율 | 오차 |
|---|---:|---:|---:|---:|
| 0–2%    | 4,159 | 0.89%  | 0.67%  | −0.22pp |
| 2–5%    | 2,025 | 3.23%  | 2.67%  | −0.57pp |
| 5–10%   | 1,103 | 7.10%  | 5.89%  | −1.21pp |
| 10–20%  |   816 | 14.33% | 15.20% | +0.87pp |
| 20–35%  |   473 | 26.52% | 27.70% | +1.18pp |
| 35–55%  |   346 | 44.38% | 47.40% | +3.02pp |
| 55%+    |   414 | 74.27% | 76.33% | +2.06pp |

- **Expected calibration error: 0.70pp** — 표시된 확률을 액면 그대로 읽어도 됩니다.
- **AUC: 0.913** — 확률이 높은 종목이 실제로 더 자주 돌파합니다.
- 높은 확률 구간에서 실제값이 예측보다 2~3pp 높은 **보수적** 편향이 있습니다.

## 기각한 변형

트렌드 상태(MA20 상/하)로 조건부 빈도를 구하고 Beta 사전분포로 축소하는
변형을 같은 9,340건으로 비교했습니다.

| 변형 | AUC | ECE |
|---|---:|---:|
| 조건부 + 축소 | 0.9027 | 0.73pp |
| 변동성 표준화만 (채택) | 0.9038 | 0.67pp |
| 표준화 없는 원시 빈도 | 0.8990 | 0.68pp |

두 추정값의 상관계수가 0.996으로 사실상 구분되지 않아, 더 단순한 쪽을
채택했습니다. 추세 정보는 주도주 점수의 별도 항목으로 반영되므로 손실이 없습니다.

## 한계

- 개별 종목의 과거 변동 패턴이 유지된다는 가정에 의존합니다. 시장 전체 충격이나
  종목별 이벤트(공시·유상증자 등)는 반영하지 않습니다.
- **예보가 아니라 빈도**입니다. "이런 설정에서 과거에 이만한 움직임이 얼마나
  자주 나왔는가"이지, 오늘 오를 것이라는 예측이 아닙니다.
- 거래대금은 KRX 공식 OpenAPI(일별매매정보)의 실제값을 사용합니다. 이 API는
  2010-01-04부터 제공하므로 그 이전 구간은 `거래량 × (시+고+저+종)/4` 추정치로
  대체합니다. 실제값 **93,854봉**과 대조한 추정 오차는 아래와 같습니다.

  | 지표 | 값 |
  |---|---|
  | 중앙값 \|오차\| | **0.50%** |
  | 90분위 | 1.75% |
  | 99분위 | 4.87% |
  | 1% 이내 비율 | 75.3% |
  | 5% 이내 비율 | 99.1% |
  | 평균 부호오차(편향) | +0.15% |

  초기에 58건 표본으로 추정한 0.70%(90분위 2.46%)보다 실제로는 더 정확했습니다.
  재현: `scripts` 없이 사이트의 `data/stocks/*.json` 에서 `a`(실제)와
  `v×(o+h+l+c)/4`(추정)를 비교하면 됩니다.
